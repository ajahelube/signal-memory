Signal Memory

Signal Memory tracks public crypto calls from opted in creators, stores them on Walrus with timestamps, checks prices through Tatum, and gives each source a trust score that fades over time.

How it works

  1. 1
    Track the callAn opted in creator makes a public call. We save who said what, and when.
  2. 2
    Store it on WalrusThe record is written to Walrus with a timestamp, so it cannot be quietly changed later.
  3. 3
    Check the price via TatumWhen the deadline comes, we check the live price through Tatum.
  4. 4
    Trust score decaysA right call raises the score and a wrong call lowers it. Older calls fade, so recent ones count more.
