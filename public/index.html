Signal Memory

Signal Memory saves crypto calls from X accounts before anyone knows if they are right.

Later it checks each call against the real price and gives every account a trust score.

Every record is stored on Walrus, so it can't be edited or deleted.

How it works

  1. 1
    Call savedAn account says "SOL will hit $200". We save it with the date.
  2. 2
    Price checkedWhen the deadline comes, we check the real price.
  3. 3
    Trust score updatedRight calls raise the score. Wrong calls lower it.
